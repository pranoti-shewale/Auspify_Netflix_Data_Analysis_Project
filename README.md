# Netflix Data Analysis Using Python

## Project Overview

This project focuses on analyzing Netflix data using Python to discover meaningful patterns and insights from the available Movies and TV Shows.

The project covers data cleaning, data exploration, data visualization, and final analysis using popular Python libraries.

## Project Objectives

* Clean and prepare the Netflix dataset
* Explore the structure and characteristics of the data
* Analyze Movies and TV Shows
* Perform country-wise content analysis
* Analyze year-wise content trends
* Explore Netflix genres
* Create meaningful visualizations
* Extract useful insights from the dataset

## Tasks Completed

### Task 1: Netflix Data Cleaning & Preparation

* Loaded the Netflix dataset
* Checked the dataset structure
* Identified missing values
* Handled missing and inconsistent data
* Cleaned text columns
* Prepared the dataset for analysis

### Task 2: Netflix Content Type Analysis

* Analyzed Movies and TV Shows
* Compared the number of Movies and TV Shows
* Created bar chart visualization
* Created pie chart visualization
* Studied the overall content distribution

### Task 3: Country-Wise Netflix Content Analysis

* Analyzed Netflix content by country
* Identified countries with the highest number of titles
* Compared content production across countries
* Visualized the Top 10 countries

### Task 4: Year-Wise Content Analysis

* Analyzed Netflix content across different years
* Studied content growth over time
* Examined yearly trends
* Compared the distribution of content across years

### Task 5: Genre Analysis

* Analyzed Netflix content genres
* Identified frequently occurring genres
* Compared different content categories
* Visualized popular genres

### Task 6: Final Analysis & Conclusion

* Summarized the findings from all analysis tasks
* Identified important patterns and trends
* Combined the results of data exploration and visualization
* Presented the overall conclusion of the project
